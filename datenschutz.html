2. Grundsatz

Diese App wurde so gestaltet, dass so wenig personenbezogene Daten wie möglich verarbeitet werden. Die App enthält keine Werbung, kein Tracking und keine Analyse-Werkzeuge. Es werden keine Daten an Dritte verkauft oder zu Werbezwecken weitergegeben.

3. Nutzung ohne Konto (Standard)

Die App ist ohne Registrierung vollständig nutzbar. In diesem Fall werden alle erfassten Daten ausschließlich lokal auf deinem Gerät im Speicher des Browsers (localStorage) abgelegt. Sie werden nicht an uns oder an Dritte übertragen.

Lokal gespeichert werden:

  • erfasste Dienstzeiten (Datum, Start, Ende, Dauer, Pausen)
  • selbst angelegte Tätigkeitsbezeichnungen
  • App-Einstellungen (Rundung, Exportformat, Monatssoll)

Diese Daten kannst du jederzeit über die Einstellungen der App („Alle Daten löschen“) oder durch Löschen der Browserdaten vollständig entfernen.

4. Optionale Cloud-Synchronisierung

Wenn du die Cloud-Synchronisierung nutzen möchtest, kannst du freiwillig ein Konto anlegen. Erst dann werden Daten an einen Server übertragen. Ohne Registrierung findet keine Übertragung statt.

Dabei wird technisch bedingt deine IP-Adresse an Google übertragen.
